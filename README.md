# Mi TV Remote

Android app that controls a Xiaomi TV (Android TV / Google TV models) over Wi‑Fi.

**Download:** [Mi-TV-Remote.apk](../../releases/latest/download/Mi-TV-Remote.apk)

## First use
1. Phone and TV on the same Wi‑Fi, TV switched on.
2. Open the app → tap your TV (or *Enter IP*).
3. Type the 6‑character code shown on the TV. Done — this is needed only once.

Features: D‑pad (hold to repeat), back/home/menu, power, input, settings, volume/mute,
channels, number pad, media keys, YouTube/Netflix/Prime shortcuts. The phone's own
volume buttons control the TV volume while the app is open.

Each push to `main` builds a new APK automatically (GitHub Actions) and publishes it under Releases.
